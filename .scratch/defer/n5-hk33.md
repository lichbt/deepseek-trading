# N5 — is HK33 actually reachable, or structurally unfit?

VERDICT: PASS — the mechanism DOES rescue HK33. Suite 1315 passed, exit 0.
This answers the MECHANISM question only; whether the queued candidate earns a
slot is a separate evaluate run and was not in scope.

## The concern this node existed to test

Raised at the end of N2: `deferred_drain` supersedes any intent whose `broker_day`
differs from today's, and the drain only fires while the pod is awake. So being
shut at the pass does NOT guarantee an instrument is reachable — if its session
reopened only after the broker day rolled, the intent would be dropped unfired and
the sleeve would silently never trade. N4 proved the property for AU200. HK33 had
never been measured, and it is shut at the pass in EVERY season.

## HK33's real schedule (live from the broker, Europe/Bucharest)

Three sessions per weekday, not one:
  04:15–07:00 · 09:00–11:30 · 12:15–21:59

HK33 is shut at the pass on every single weekday — and reopens 1–2h later, inside
the same broker day, on every single one. The mechanism reaches it.

**AU200 reproduces N4 exactly (450 / 334 / 0)** through a second, independent
implementation: N4 stepped forward in 5-minute increments, this sweep computes the
next interval start directly from the schedule. Two different methods, identical
counts.

## Second finding: HK33 was carry-free by omission, exactly as AU200 was

`HK33_HKD` appeared in NEITHER swap table, so `swap_charge()` returned 0.0 and
every HK33 backtest in this repo was gross of rollover. That covers the retired
`hk33hkd_auto_20260711_211002_i27` and the candidate
`hk33hkd_auto_20260812_195735_i10` currently at status `passed`.

Now added: **-0.0000251/day, ~0.92%/yr** (swapLong -61.76, pipPosition 2 ->
-0.6176 HKD/unit/day / ~24,600), and registered in `SWAP_DERIVED`.

**The conversion rule was calibrated before being trusted.** It reproduces the
three MEASURED rates in the file to within 0.4%:

| | derived from card | measured | error |
|---|---|---|---|
| NAS100_USD | -35.750 | -35.875 | 0.35% |
| XAG_USD | -0.04290 | -0.04280 | 0.23% |
| XAU_USD | -0.89100 | -0.89000 | 0.11% |

So the arithmetic is sound and the AU200 rate shipped in N1 is confirmed by the
same check. What stays provisional is the broker's HSI card itself: 0.92%/yr is a
real outlier against AU200's 11.4% and NAS100's 45%, and no HK33 position has ever
been held on this account to check it against an accrual.

## What this does NOT establish

- That `hk33hkd_auto_20260812_195735_i10` should be deployed. It has had no
  evaluate run, and it now needs one against a costed backtest rather than the
  carry-free one it passed under.
- That HK33's intraday breaks are harmless. It has two gaps a day (07:00–09:00,
  11:30–12:15) and a broker stop can be gapped through them. AU200 has one.
- Anything about HK33's spread, which at ~0.045% round trip is the widest in the
  index set after CN50.
